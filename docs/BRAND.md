# Iterail identity and provenance

Iterail combines iteration and rail: a repeatable path for work to advance. The
returning track, rising arrow and separate checkpoint are simple project-authored
geometry. The owner requested restoration of the earlier Iterail identity for this
repository. The two SVG lockups are copied byte-for-byte from this project's earlier
editable vector work, following inspection of their source and rendered previews.
They are not downloaded logos, traced third-party artwork or new model generation.

- `assets/brand/logo-light.svg`: ink #101827 and green #4DE0B0 for light backgrounds.
- `assets/brand/logo-dark.svg`: white #F7FAFC and green #4DE0B0 for dark backgrounds.

README uses a theme-aware picture element. The mark and wordmark are editable;
SVG text uses Avenir Next/Helvetica Neue/Arial system fallbacks, so letterforms may
vary by platform. No font files, scripts, external references, embedded raster data,
concept reference image, draft brand notes or operational evidence are distributed.
